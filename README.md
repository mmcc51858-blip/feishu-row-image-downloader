# 本行套图下载

飞书多维表格边栏插件。默认选择“套图输出”，点击单元格选中该行，点击“打包下载套图”，然后点击“保存 ZIP 文件”。也可通过左侧行号或官方记录选择器多选记录。

## 安装

在多维表格的插件入口打开“自定义插件”，点击“新增插件”。运行地址填写：

https://mmcc51858-blip.github.io/feishu-row-image-downloader/

名称可填写“本行套图下载”。如果入口只要求运行地址，填写地址即可。

公开源码与静态网页不包含应用密钥、表格地址、记录、附件或下载链接。浏览器通过飞书官方 SDK 读取当前用户有权访问的记录和附件。插件不修改表格，不使用外部下载代理。

## 开发

Node.js 22.12+（已使用 Node.js 24 验证）。

```sh
npm ci
npm run dev
npm test
npm run build
```

`dist/` 是可托管的静态插件。GitHub Actions 自动构建并发布到 Pages。飞书客户端需能访问托管地址。

独立网页不具备飞书宿主上下文，只显示安装提示。地址添加 `?demo=1` 可验证六张示例 SVG 的 ZIP 打包和保存；示例不会读取真实表格。

## 命令行下载

也提供不依赖浏览器登录的 CLI，使用飞书开放平台应用凭证。应用必须具有表格读取和素材下载权限，并能访问目标表格。凭证通过进程环境变量传入，不能放在网页或提交到仓库。

```powershell
$env:FEISHU_APP_ID = '你的应用ID'
$env:FEISHU_APP_SECRET = '你的应用密钥'
node cli/download.mjs --url '多维表格网页链接' --row 1 --field '套图输出' --out '套图.zip'
```

`--row` 按接口返回的记录顺序从 1 开始；精确选择时使用 `--record recXXXX`。CLI 不读取网页视图的排序或筛选，输出所用记录 ID 便于核对。支持分页读取。多张附件重名会自动编号，任何下载失败都会中止，不生成看似完整的包。

## 限制与验证

浏览器单次最多 512 MB，超出请分批下载。多行附件按“记录_1”等子目录保存。失败项目写入 ZIP 内的未下载清单；全部失败时不生成 ZIP。浏览器直接读取附件依赖飞书临时链接允许跨域及租户下载权限，不绕过权限限制。

自动化测试验证路径清理、重名保留和 ZIP 原始字节。真实开放接口下载与宿主内 SDK 验证分别记录，不以示例模式通过代表已在飞书完成安装。
